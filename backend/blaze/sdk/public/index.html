NexCent popup SDK

Embed an intent-based popup on your Shopify storefront with one snippet.

Install

<script async
        src="https://YOUR-PROJECT.web.app/v1/popup.js"
        data-api-key="ank_live_…"></script>

Paste this right before </body> in theme.liquid.
